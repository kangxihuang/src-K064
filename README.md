# (附文档)Springboot3+Vue3+MySQL 在线考试系统

**技术栈**：Springboot3、Vue3、MySQL

### 系统简介

本系统是一套基于 Spring Boot 3 + Vue 3 + MySQL 的前后端分离在线考试平台。支持管理员、教师、学生三种角色，涵盖题库管理、试卷组卷、在线考试、自动阅卷、成绩统计、班级管理、系统监控等完整考试业务链路。
 
### 核心功能
 
### 管理员端

 
- 用户管理：分页查询用户列表（支持按角色/关键字/班级筛选）、新增/编辑/删除用户、重置用户密码为 123456 
- 批量导入用户：下载 Excel 导入模板，上传文件批量创建学生/教师账号并自动分配班级 
- 班级管理：分页查询班级列表（显示学生人数）、新增/编辑/删除班级、按年级/专业关键字搜索 
- 学科分类管理：查看分类列表（显示题目数量）、新增/编辑/删除分类 
- 系统公告管理：分页查询公告、新增/编辑/删除公告、设置置顶与发布状态 
- 系统日志监控：分页查看操作日志（记录操作人/操作/方法/状态）、删除单条日志、一键清理 30 天前日志 
- 系统数据概览：查看考试记录数、答题数、日志总数、上传文件大小/数量 
- 考试数据清理：清理 3 年前的考试记录及对应答题数据 
- 数据库备份提示：返回 mysqldump 命令与上传目录路径 
- 意见反馈管理：分页查看用户反馈（支持按状态/类型/关键字筛选）、回复反馈内容
 
### 教师端

 
- 题库管理：分页查询题目（支持按题型/分类/难度/关键字筛选）、新增/编辑/删除题目 
- 批量导入题目：下载 Excel 模板，上传文件批量创建题目（支持单选/多选/判断/主观题） 
- 试卷管理：分页查询试卷（支持按分类/关键字/状态筛选）、新增/编辑/删除试卷 
- 手动组卷：从题库中选择题目并设置每题分值，保存为试卷 
- 随机组卷：按题型规则（单选题数量与分值/多选题数量与分值/判断题数量与分值/主观题数量与分值）自动从题库抽取题目组成试卷 
- 试卷启停：启用或停用试卷，停用后不可用于新考试 
- 考试管理：分页查询考试（支持按关键字/状态/创建人筛选）、新增/编辑/删除考试 
- 设置考试参数：关联试卷、设置考试名称/开始时间/结束时间/防作弊开关、选择参与班级（支持多班级） 
- 启停考试：一键开始或结束考试 
- 考试记录查询：查看所有考试记录（支持按考试/学生/班级/状态/关键字筛选） 
- 主观题阅卷：查看学生答题详情，对主观题逐题评分并提交成绩 
- 成绩统计：查看指定考试的成绩分布（最高分/最低分/平均分/及格率/各分数段人数）
 
### 普通用户端（学生）

 
- 考试列表：查看自己可参加的考试（按进行中/未开始/已结束分类），显示考试状态与个人记录 
- 开始考试：进入考试页面，系统自动创建考试记录并显示题目（支持题目乱序） 
- 在线答题：逐题作答，支持单选/多选/判断/主观题输入 
- 交卷：提交答案后系统自动计算客观题得分，主观题等待教师阅卷 
- 异常行为上报：考试过程中上报异常行为（如切屏），记录到考试记录中 
- 考试记录详情：查看已完成考试的答题详情，包括每道题的答案、正确答案、得分与解析 
- 错题本：查看所有错题列表，显示题目内容、正确答案与解析 
- 个人成绩统计：查看个人考试总次数、平均分、最高分、最低分、及格率等统计 
- 修改个人信息：修改昵称/性别/手机号/邮箱等资料 
- 修改密码：输入旧密码与新密码完成密码修改 
- 提交意见反馈：填写标题/类型/内容提交反馈，查看管理员回复
 
### 技术栈

 后端框架Spring Boot 3.2 ORMMyBatis-Plus 3.5 权限认证JWT Token（自定义拦截器） 前端框架Vue 3 + Element Plus 状态管理Pinia 构建工具Vite 数据库MySQL 8.0 文件上传MultipartFile + 本地目录存储 Excel 导入导出EasyExcel
